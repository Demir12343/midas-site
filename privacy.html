Privacy Policy - Midas Bot

Last updated: October 28, 2026

Midas Bot ("we", "the bot") is a Discord bot that uses Epic Games Account Services to verify the Epic Games accounts of Discord server members. This page explains what information we collect, how we use it, whether we share it, and how long we keep it.

1. What Data We Collect

When a user connects their Epic Games account through Midas Bot, we receive and store the following information via Epic's official OAuth login:

  • Epic Games Account ID
  • Epic Games Display Name (username)
  • The user's Discord ID (to link the Discord account with the Epic account)

We do not collect, request, or have access to the user's Epic Games password, payment information, or any other personal account data. Users only grant access through Epic's own secure login page, and only the above-listed information is returned to us.

2. How We Use This Data

The collected data is used solely to:

  • Verify that a Discord member owns a genuine Epic Games account
  • Assign a "Verified Account" role to the user on our Discord server
  • Display the user's Epic Display Name and Account ID in a confirmation message
  • Keep an internal log of successful verifications for moderation purposes
  • Show Fortnite statistics when requested by the user

3. How We Share This Data

We do not sell, rent, or share any collected data with third parties, advertisers, or other services. The data is only visible to the server's administrators and is used exclusively within the Midas Bot Discord server for the purposes described above.

4. Data Retention

We retain the Epic Account ID, Display Name, and linked Discord ID for as long as the user remains a member of the server and keeps the "Verified Account" role, so the connection can be recognized on future logins. If a user leaves the server, their stored data is deleted within 30 days.

5. Your Rights / Data Deletion

You may request the deletion of your stored data at any time by contacting a server administrator on the Midas Bot Discord server and asking to be unlinked. Upon request, we will remove your Epic Account ID, Display Name, and Discord ID from our records within a reasonable time frame.

6. Contact

For any privacy-related questions or data deletion requests, please contact the server administrators directly on Discord.

Midas is not affiliated with, endorsed by, or sponsored by Epic Games, Inc.
